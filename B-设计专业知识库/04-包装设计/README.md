# 包装设计

## 01 基础规范
包装功能与保护、用户体验、结构与尺寸、材料选择、印刷色彩、刀版与出血、工艺、标签信息、法规要求、运输与可持续性。具体参数须按材料、供应商和适用法规核实。

## 02 设计案例参考
记录品类、定位、消费人群、货架环境、结构、开合方式、视觉系统、材料工艺、成本与环保考量。

## 03 设计方法
市场与竞品调研 → 品牌/产品定位 → 结构探索 → 视觉概念 → 刀版适配 → 材料工艺打样 → 测试与量产交付。

## 04 提示词
包装风格研究、结构草图、正背侧展开图、材质工艺效果、场景 mockup。必须明确要求结构尺寸与展开图一致，不能用效果图替代生产刀版。
