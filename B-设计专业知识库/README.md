## 每个专业的固定结构
1. **基础规范**：概念、术语、原则、尺寸、比例、网格、材料、工艺、输出或可用性要求。
2. **设计案例参考**：背景、目标、策略、视觉/结构/交互特征、成果与可借鉴点。
3. **设计方法**：调研、定位、概念、草图、迭代、验证、制作和交付。
4. **提示词**：调研分析、创意构思、草图生成、效果图、局部修改和质量检查。

## 案例分析框架
项目背景 → 目标受众 → 核心问题 → 设计策略 → 信息/视觉层级 → 构图与色彩 → 字体与图形 → 材料/工艺/交互 → 成果评价 → 可借鉴方法 → 来源。

可扩展：字体设计、书籍装帧、导视设计、文创设计、展示设计、品牌设计、信息图形等。
