# 平面设计

## 01 基础规范
版式与网格、对齐与层级、字体与可读性、色彩管理、图文关系、印前与输出、跨媒介适配。

## 02 设计案例参考
记录项目背景、传播目标、受众、信息层级、版式策略、字体/图形/色彩、应用场景、成果与来源。

## 03 设计方法
需求分析 → 信息梳理 → 概念定位 → 网格与版式探索 → 字体/图形系统 → 多尺寸适配 → 校对与输出。

## 04 提示词
调研与风格分析、版式方向探索、字体与图形组合、视觉稿生成、尺寸延展和印前检查。
