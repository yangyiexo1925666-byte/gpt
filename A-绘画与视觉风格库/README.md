## 收录维度
定义与背景、线条与造型、构图与空间、色彩与光影、材质与技法、代表艺术家/作品、适用场景、提示词与负面约束。

## 案例规范
每条案例尽量记录作品名、作者/机构、年代、媒介、原始来源链接、风格标签及个人分析。未核实的信息标注“待核实”，不猜测作者或出处。
