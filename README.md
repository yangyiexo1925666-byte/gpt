## 外部灵感与案例参考
- [Pinterest](https://www.pinterest.com/) — 视觉灵感、绘画风格与设计案例发现平台。

Pinterest 用于发现和整理灵感。正式收录案例时，请尽可能记录具体 Pin 链接、作者/机构、作品名称、风格标签和个人分析；Pinterest 页面不一定是作品原始出处。

## 统一收录原则
1. 分类清晰：A 关注视觉风格本体，B 关注专业设计门类，C 负责跨领域方法与整合。
2. 可追溯：保留原始出处、作者/机构和访问日期（如可查）。
3. 可复用：规范、方法与提示词整理为可检索、可执行的条目。
4. 有分析而非堆图：记录设计目标、视觉特征、构图、色彩、字体/材质、适用场景和可借鉴之处。
5. 持续迭代：新增资料先归类，使用统一模板；重复内容合并并保留来源。
